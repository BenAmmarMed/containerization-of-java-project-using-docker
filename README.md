## Prerequisites

Before running the project locally, make sure you have:

- JDK 17 or 21
- Maven 3.9
- MySQL 8

## Technologies

The project uses:

- Spring MVC

- Maven
- JSP
- Tomcat
- MySQL
- Memcached
- RabbitMQ
- Elasticsearch
